# Tender Intelligence

A prototype for simplifying government tender information.

## Current Prototype

The system converts tender data into a simple tender opportunity card.

## Current Information

- Work
- Location
- Department
- Tender Value
- Closing Date
- Eligibility
- EMD
- Required Experience
- Completion Period
- Payment Terms
